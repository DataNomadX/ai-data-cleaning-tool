# 🧹 CleanData AI

**Turning ideas into reality using AI.**

CleanData AI is a smart, guided data cleaning tool that helps transform raw, messy datasets into clean, analysis-ready data, without requiring deep technical expertise.

---

## 🚀 Overview

This project demonstrates how AI-assisted development can turn a simple idea into a fully functional product.

The idea started with a common problem:

> Cleaning data is time-consuming, repetitive, and often confusing.

CleanData AI solves this by:

* Automatically analyzing datasets
* Detecting common data issues
* Suggesting intelligent cleaning steps
* Allowing users to apply fixes interactively

---

## ✨ Features

* 📂 Upload CSV datasets
* 🤖 AI-driven cleaning suggestions
* 🩹 Handle missing values (mean, median, mode)
* 🔁 Remove duplicate rows
* 🔀 Fix incorrect data types
* ✂️ Clean text (trim spaces, standardize casing)
* 📐 Detect & handle outliers (IQR method)
* 📊 Built-in visualizations for quick insights
* 🇮🇳 Indian dataset support (phone numbers, pincodes)
* 📋 Domain templates (Survey, Sales, Student data)
* 💾 Download cleaned dataset

---

## 🛠️ Tech Stack

* **Python**
* **Streamlit**
* **Pandas**
* **NumPy**
* **Plotly**

---


## 💡 How It Works

1. Upload a CSV file
2. The app analyzes your dataset automatically
3. Suggested cleaning steps are generated
4. Select the steps you want to apply
5. Download the cleaned dataset

---

## 🎯 Use Cases

* Data preprocessing for machine learning
* Cleaning survey or business datasets
* Exploratory data analysis (EDA)
* Academic and student projects

---

## 🌍 Vision

This project reflects a bigger idea:

> With the help of AI, developers can move faster from idea → execution → real-world solution.

CleanData AI is a small example of how combining human thinking with AI tools can simplify complex tasks and make technology more accessible.
